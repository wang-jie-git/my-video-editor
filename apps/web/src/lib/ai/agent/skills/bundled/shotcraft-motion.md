# 电影感镜头动效配方（shotcraft-motion）

> 来源：github.com/Vincentwei1021/video-shotcraft（Apache-2.0）知识层提炼。
> 原库是 Remotion 代码实现；本技能只保留**平台无关的镜头语言、帧级参数与判例**，
> 全部适配到本编辑器的时间线工具（update_element / concat_with_transitions /
> adjust_video_speed / add_text_to_timeline / fade_audio / mix_audio）。

## 一、核心理念（四条铁律）

1. **复刻既有页面必须用真实截图**；手搓 UI 限非复刻场景（抽象开场/品牌段/独立组件），且质量必须出版级、表达必须观众一眼看懂。数据按风险口径：客户/个人/内部/密钥数据必须虚构或脱敏。
2. **视觉语言从产品自身生长**：做动效前先提取产品设计系统（字体、栅格、圆角、色板）作为 tokens，所有标题/字幕/配色/光效必须复用这套 tokens——不另造"宣传片皮肤"。
3. **电影感来自运镜、光影、节奏与声音的配合，不来自炫技动画**。单主角完整动作弧（聚光→推近→悬浮→归位）、物理隐喻驱动的加速度（发牌）、riser→impact→sparkle 声音句式。
4. **每个镜头只讲一个动效；关键信息落定后必须呼吸**。一种动画手法全片只当一次主角；重复镜头、重复手法、连续高能量 = 嘈杂。

## 二、全片能量骨架（30–60s 产品宣传片默认结构）

| 段位 | 时长占比 | 能量 | 职责 |
|------|----------|------|------|
| ① 品牌开场 | 8–12% | 低 | 字标压印 + hold ≥1s，交棒产品页面 |
| ② 单主角立传 | 12–15% | 中（质感最高、节奏最慢） | 一个主角、一条完整动作弧 ≥3s，立出产品原子单位 |
| ③ 功能爬升段 | 55–65% | 中高⇄低交替 | 每镜绑一个独特功能、一种手法只当一次主角；镜间插呼吸字卡 |
| ④ 发布会收场 | 13–16% | 峰值 | 已展示功能各出代表元素合影围住字标，sign-off hold ≥1s |

- 呼吸字卡：每 1–2 个功能镜头后插一张，单张 ~1.8s（50–55f），全片 2–4 张
- ③ 段能量交替：高能量镜（发牌/堆叠）与稳节奏镜（交互/读字段）间隔排列；信息密度最高的镜头放峰值收场之前
- 骨架是默认项不是令：15s 短片/单功能产品可大胆合并段位，但 ①hold 与 ④峰值两端不可省

## 三、精选配方卡（12 张，按类别）

### 开场（opening）

**spotlight-hero-card（主角聚光立传）**
- 适用：单主角完整动作弧；时长 ≥3s
- 核心：聚光→推近→悬浮→归位。光源先亮（spotlight 扫过）→ 卡片从暗处推近 → 悬浮微浮（y 轴 sin 微动 ±8px）→ 归位静止 ≥30f
- 参数：聚光 0.8s（24f）、推近 1.2s（36f）ease-out、悬浮持续 0.8s、归位 0.4s（12f）
- 坑：悬浮幅度 >20px 读作乱飘；聚光不打到主体直接切 = 观众不知道看哪

### 转场（transition）

**line-carry-transition（线条接力横移，招牌转场）**
- 适用：两个有图形亲缘的场景之间（进度条→卡框）；全片 ≤1 次
- 核心：场景 A 的进度条延伸出画，镜头跟线横移，线在移动中拐直角围出场景 B 的卡框，全程无剪切
- 参数：横移 1920px / 60f（32px/f）；笔头钉在画面 x≈78% 处；框闭合后再淡入内容
- 坑：>40px/f 笔头拖影跟丢；起点必须是已有图形构件的自然延伸，凭空起线 = 屏保
- 声音：线生长一声持续笔擦、框闭合一声轻叩

**color-block-step-wipe（离散阶跃色块吞屏）**
- 适用：品牌色转场/章节交接；"硬朗无缓动"的像素游戏手感
- 核心：全程零插值零缓动——色块 3–5 步硬跳扩成全屏，每跳都是硬切，跳间完全静止
- 参数：跳位间隔 6–12f 不等距；徽章三跳过冲 0.55→1.12→1；铺满后 ≥30f 纯色 hold
- 坑：等距跳读作 GIF 掉帧；全片到处阶跃就没人信这是设计；**每跳一声打点**，无声版阶跃会被读作播放器卡顿

**card-flip-reveal（功能卡 3D 翻面揭示）**
- 适用："功能→成果"成对叙事：正面 UI 界面翻出背面大号结论数字
- 参数：单卡翻转 26f（18f 冲 192° 过冲 + 8f 回落 180°）；侧棱高光随角度 35°→145° 扫过、90° 最薄时达峰；多卡错峰 10f/卡；全翻完 hold ≥40f
- 坑：翻转 <14f 看不到侧棱瞬间；高光不与角度联动 = 光在乱闪

### 特效（effects）

**draw-svg-trace（SVG 描边点名）**
- 适用：元素级描边、强调某个 UI 区域
- 核心：path 的 dasharray/dashoffset 从 0 生长到全长
- 参数：描边 1.2–2s；笔头圆点 r=6–11 随线走；收尾笔头条件卸载
- 坑：描太快（<0.8s）观众跟不上；线宽 <2px 在 1080p 下读丢

**particle-aurora（粒子极光背景）**
- 适用：品牌开场/背景氛围；数据可视化场景
- 核心：多层粒子场（远 blur + 中实 + 近焦外），正弦 wobble 让群体"活着"
- 参数：三层景深 blur 7/0.5/9；粒子数 20–60；wobble 振幅 10–32px、sin(f×0.09)
- 坑：全实心读作贴纸雨；振幅 >50px 读作乱流

### 节奏（rhythm）

**number-count-roll（数字滚动）**
- 适用：指标/统计数字登场
- 核心：数字从 0 滚到目标值，ease-out 减速 + 千分位格式；滚完落定 hold ≥30f
- 参数：滚动时长 1.2–2s；减速曲线 easeOutCubic 或 poly(3)
- 坑：匀速滚动 = 计数器读秒；落定不停顿直接切镜 = 数字没被"看到"

**beat-pump（节拍泵，全片 ≤1 次）**
- 适用：强节奏 BGM 段落的元素层节拍呼吸
- 核心：元素 scale 随 kick 脉冲，连打单次 ≤4 拍
- 参数：泵幅 1.02–1.06；ease-out 回落
- 坑：**整画面级冲击全片 ≤3 处**——逐拍 pump 叠在相机层就是"镜头随节奏抖动"（判例：用户反馈"如果给音乐，镜头会随节奏抖动，影响观感"）。只动元素层，不动相机层

### 交互（interaction）

**type-and-filter（搜索框打字筛选）**
- 适用：模拟真实交互（搜索/筛选）
- 核心：按真人操作速度打字（~5–8 字/秒）→ 结果列表随筛选项逐条更新
- 参数：打字 2.5–3.5s；结果更新 0.3s/条、逐条错峰
- 坑：打字太快读作"自动填充"；结果一次全换 = 观众不知道哪个条件触发了哪个变化

### 文字（typography）

**split-flap（翻牌式字符揭示）**
- 适用：标题/关键词登场；机械感、数据感
- 核心：每个字符垂直翻转 90°→-90° 换字，错峰 2–3 字符/拍
- 参数：单字符翻转 12–16f；错峰 4–6f；bezier(0.55,0,0.3,1)
- 坑：字符同步翻转 = 整块翻页；翻太快（<8f）看不清换字过程

### 数据（data）

**chart-draw-up（图表生长）**
- 适用：折线/柱状图从 0 长到数据值
- 核心：柱体 scaleY 0→1 按顺序错峰（从左到右），折线 dashoffset 生长
- 参数：整体 1.5–2.5s；柱间错峰 3–5f；生长完 hold ≥30f
- 坑：柱体同步生长 = 一张图"浮现"而非"生长"；生长完不 hold 观众记不住数值

### 转场（camera）

**match-cut（形状对位剪切）**
- 适用：两个形状相似的画面之间（圆形→圆形、线条→线条）
- 核心：切点两侧形状、位置、方向严格对位——观众无感"切"但感觉到"变"
- 参数：对位误差 ≤1.5%；切前 hold ≥12f 让观众看清前画面的形状
- 坑：对位偏差 >5% 读作硬切；没有图形亲缘硬凑 match-cut = 迷惑剪辑

### UI 入场（ui-entrance）

**deck-deal-flyin（发牌式批量入场）**
- 适用：多张卡片/多元素批量入场；"越堆越快"的物理隐喻
- 核心：卡片像发牌一样从一角飞出、依次归位，**归位越来越快**（硬加速），满板后静止 0.5s
- 参数：首批 8–10f/张、末批 3–4f/张（加速）；飞行路径弧线 ease-in-out；收尾静置 15f
- 坑：匀速入场读作廉价 PPT（判例：用户要求"卡片不断往下堆叠时，应该越来越快，并在最后停顿0.5秒"）；抽象 flood 五轮不收敛、换发牌隐喻一轮通过

## 四、节奏卡点方法论（BGM 强节奏片）

**铁律：音乐先行。** 网格验收通过前不设计分镜；时长对不上改时间参数、不删用户文案；浮点秒记录时刻、最后一帧才取整（提前取整误差滚雪球）。

1. **测定节拍网格**：librosa 的 beat_track 得到 tempo 标量可能偏差 2%+，但 beat 时刻序列本身可信——对 beat 序列做最小二乘等距网格拟合求真实 BPM 与相位。验收：残差 ≤±15ms。
2. **半倍/双倍歧义必查**：70 BPM 报成 140 常见。判据：正确网格下 kick 主要落在整数拍；kick 一半落拍一半落半拍 = 网格快了一倍。
3. **鼓点分类驱动动效**：
   - kick（40–160 Hz）→ 冲击/slam/骤缩——画面"被砸"的一拍
   - snare（150–500Hz + 1–3kHz）→ 替换/闪切/构图切换——"换一件事"的一拍
   - hihat（6–14 kHz）→ 微动密度——hihat 密的段落微动效可以密，稀的必须收
4. **整画面级冲击 ≤3 处**：钉最强 hit 清单、相邻间隔 ≥16 拍；其余拍点只动元素层。
5. **渲后回测**：成片逐切点对拍号，误差 ≤3 帧（感知阈值）。

## 五、声音设计准则

**顺序：画面结构锁定 → 先铺 BGM 定能量骨架 → 逐拍钉 SFX。** 声音永远排在画面锁定之后——画面再改 SFX 全表报废重钉。

- **BGM**：全片一条铺底；音量 ~0.34 给 SFX 留 headroom；首尾 1s 淡入 / 1.7s 淡出。产品宣传片优先电子底（tech-house 类鼓点强），"好听/欢快"不是判据；**候选曲必须垫进成片试听**（判例：v1 钢琴 ambient、v2 folk-pop 都被一耳朵否，"太像游戏了"）。
- **SFX 词汇按片种选、不按事件选**：产品宣传片 = whoosh（运镜）/ impact（落地）/ riser（铺垫）/ sparkle（光效）/ transition（转场）。**禁用游戏音包音色**（合成器 pluck/bloop、卡通弹跳）——判例：按 UI 事件语义选音（click/drop/confirmation）被否"太像游戏了"。禁的是音色不是动作：画面真有点击/碎裂就该配真实拟音。
- **SFX 逐拍钉帧、声明式集中管理**：每条 `{ from, src, volume }` 加注释对应画面动作——杜绝凭感觉铺音效。
- **免费授权来源**：Mixkit（免费商用免署名，BGM + 电影系 SFX）；incompetech CC-BY（需署名）；Kenney CC0（**产品宣传片禁用**）。下载时就记录曲名/URL——Mixkit 批量下载后 metadata 常被抹掉，事后无法反查。

## 六、落地映射（我们的工具怎么实现这些配方）

| 配方卡 | 本编辑器工具链 |
|--------|---------------|
| spotlight-hero-card | update_element（位置/缩放/透明度关键帧）+ 聚光层（CSS 径向渐变元素） |
| line-carry-transition | concat_with_transitions 的平移转场 + 进度条元素延伸动画，或导出后用 FFmpeg 位移滤镜 |
| color-block-step-wipe | 色块元素 3–5 次 scale/位置硬跳关键帧（零插值）+ 每跳一个音效 |
| card-flip-reveal | update_element 的 rotateY 关键帧（perspective 1200px）+ 高光层同步 |
| draw-svg-trace | 元素描边属性（stroke-dasharray 关键帧） |
| number-count-roll | add_text_to_timeline 数字文本 + 每帧更新数值（easeOutCubic） |
| beat-pump | 元素 scale 关键帧钉 kick 拍 + adjust_video_speed 对齐节奏 |
| type-and-filter | 文本逐字 update_element + 列表元素错峰出现 |
| split-flap | 文本字符逐个替换（rotateX 翻转）+ 错峰 |
| chart-draw-up | 图形元素 scaleY 错峰关键帧 |
| match-cut | 相邻镜头缩放/构图对齐后直切（concat_with_transitions 的 cut） |
| deck-deal-flyin | 多元素 update_element 弧线路径 + 加速错峰（末批间隔缩短） |

**通用实现要点**：
- 所有关键帧缓动默认 ease-out，禁止匀速直线运动（读作 PPT）
- 元素落定后 hold ≥30f 再切（呼吸感）
- 批量入场"越来越快"+ 收尾 0.5s 静止
- 全画面级冲击（scale 泵/震屏/闪帧）全片 ≤3 处
- 一个手法全片只当一次主角

## 七、验收清单（做完整片/镜头后自查）

```
□ R1 关键信息落定后是否静止 ≥1s？（每个"想让观众记住的画面"）
□ R2 有没有任何元素在做匀速直线运动？批量入场是否越来越快、末尾有无静止呼吸？
□ R3 主体动作弧是否 ≥3s？交互演示是否按真人操作速度？
□ R4 全画面级冲击是否 ≤3 处、相邻间隔 ≥16 拍？
□ Q1 复刻页面是否用真实截图？数据是否脱敏？
□ Q2 3D 透视下文字是否发糊？（纹理分辨率 ≥ 显示尺寸 2 倍）
□ S1 音色是否像游戏？闭眼只听音轨，像产品发布会预告吗？
□ S3 声音是否排在画面锁定之后？
□ C2 呼吸字卡是否与 outro tagline 文案重复？（重复即删）
```

## 八、使用说明

- 用户要求"电影感/宣传片/高级转场/动效建议"时：先判断是全片结构还是单镜头
  - 全片 → 先按「能量骨架」规划段位，再逐段选配方卡
  - 单镜头 → 直接选对应类别配方卡，按参数表实现
- 配方卡参数是**调校起点非实战定稿**——首次实战须以真实素材回验
- 与 jianying/其他技能的分工：本技能只管镜头语言与节奏设计，不涉及格式转换
